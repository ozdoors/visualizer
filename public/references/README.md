# Product style-reference photos (optional but recommended)

Drop a real photo of each railing system in this folder and the AI will use it
as a **visual style guide**, so the generated railing closely matches your
actual product hardware — not just the text description.

Name each file by its system **slug**, with a `.jpg`, `.png`, or `.webp`
extension:

| Product | File name to use |
|---|---|
| Glass Railing: Spigot with Top Rail | `glass-spigot-top-rail.jpg` |
| Glass Railing (Post and Clamps) | `glass-posts-clamps.jpg` |
| Aluminium Glass Railing | `aluminium-glass.jpg` |
| Aluminium Spindle Railing | `aluminium-spindle.jpg` |

Tips for the best results:
- Use a clean, well-lit close-up that clearly shows the hardware (posts,
  spigots, clamps, top rail, spindles) and how it mounts.
- A plain or simple background is better — the AI is told to ignore the
  reference's scenery and only copy the railing style, but a clean shot helps.
- These are optional. If a file isn't here, generation falls back to the text
  description alone (still works, just less exact).

The photos you shared (e.g. the black spigot + top-rail close-up) are perfect
for this — save them here with the matching file names above.
